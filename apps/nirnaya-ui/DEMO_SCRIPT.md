# Demo guide

The current demo instructions live in [`docs/DEMO.md`](../../docs/DEMO.md).
From the repository root, start the production API and dashboard together:

```bash
python scripts/launch_demo.py
```

The bundled refinery scenarios are synthetic and are not operational plant
data. The archived reference backend is for historical validation only; it is
not the application backend. GPU availability and execution are reported only
when actual supported hardware is detected.
