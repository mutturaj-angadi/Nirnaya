CANONICAL WINDOWS COMMANDS
Install runtime and test dependencies: python -m pip install -r requirements.txt
Launch complete local demo: python scripts\launch_demo.py
Run the full test suite: python -m pytest -q
Run independent release validation (while the demo is running): python scripts\run_release_validation.py --base-url http://127.0.0.1:8000
Run the 10,000-instance optimization validation corpus: python scripts\run_noc10k.py --workers 1
Analyze a selected corpus run: python scripts\analyze_noc10k.py --input benchmarks\results\noc10k\run_eta_final.jsonl
Run the in-process benchmark matrix: python benchmarks\run_benchmark_matrix.py --time-limit 30

DEPENDENCIES AND GPU
Python 3.10 or later is required. requirements.txt installs the five local packages, their declared NumPy/SciPy/FastAPI/Pydantic dependencies, pytest, pytest-asyncio, and httpx. The demo has no runtime network download requirement. CUDA/CuPy is optional. Nirnaya's current LP simplex executes on CPU; the GPU package supplies a GPU-ready capability/primitive layer and does not claim GPU-accelerated LP solving.

KNOWN LIMITATIONS
The solver supports continuous LPs only. Concurrent heavy API solves have no admission control and can contend for CPU; the 30-second deadline is unchanged and no service-level timing guarantee is made. The standalone historical presolve tests target removed core APIs and fail collection; current integrated presolve paths are covered by the root test suite and live validation. A network-isolated package build was unavailable in the development environment. See docs\NOC10K.md, docs\NUMERICAL_RELIABILITY.md, and docs\VALIDATION.md.

PACKAGE CREATION
This archive is built by scripts\package_release.py from an explicit project-root allowlist and generated-file exclusions. It excludes Git/Codex/IDE state, caches, bytecode, source archive bundles, duplicate historical benchmark runs, and temporary files. It includes only selected reproducible validation artifacts. The ZIP is then checked for CRC and extracted to a new directory for release tests. SHA-256 is written beside the archive as Nirnaya_SIH2026_Final_Release.zip.sha256.
